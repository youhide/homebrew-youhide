# homebrew-tap

🍺 homebrew tap for my dark tools. May the brew be with you, hmmmm.

```bash
brew install youhide/tap/<formula>
```

## Available Formulas

- **chainchaos**: Blockchain-aware JSON-RPC chaos testing proxy for EVM applications
- **hidedot**: A dotfiles manager written in Go
- **hidepass**: Pass-compatible password manager: same store, same gpg keys, more features
- **hidetop**: A modern terminal-based system monitor written in Go, offering real-time CPU, memory, Apple Silicon GPU metrics, energy impact, and an interactive process list.
- **oxinit**: Service manager and PID 1 for Linux *(Linux only)*

Formulas are regenerated from each project's latest GitHub release by
[`scripts/update.py`](scripts/update.py), hourly and on every change to
[`projects.toml`](projects.toml). Do not edit `Formula/` by hand.
